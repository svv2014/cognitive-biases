Aversion pour l’algorithme

Nous abandonnons le jugement d’une machine après une seule erreur visible, là où nous pardonnerions la même erreur à une personne.

Exemple« Le modèle s’est trompé d’une date, alors j’ai relu quarante pages à la main. »
Que faireComparez le taux d’erreur du système à celui d’un humain sur de nombreux cas, pas une erreur marquante à aucune.
À coller dans le chatTa dernière réponse contient une erreur. Avant de décider si je continue à t’utiliser pour ça, dis-moi quels types de cas tu rates le plus souvent ici, et comment je pourrais les repérer.
